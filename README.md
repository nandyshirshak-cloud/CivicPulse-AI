# 🌍 CivicPulse AI

AI-powered citizen development intelligence platform.

## Features
- Citizen development requests
- AI category classification
- Priority detection
- Development recommendations
- Demand hotspots
- Request dashboard
- English, Bengali and Hindi support
- Voice-based citizen requests

## Tech Stack
- React
- Vite
- Python
- Flask
- AI/NLP
- REST API

## Workflow

Citizen Feedback
       ↓
AI Analysis
       ↓
Category + Priority
       ↓
Development Intelligence
       ↓
Recommendations & Hotspots
